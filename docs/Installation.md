
##  Want to test this project out yourself??

Go ahead and Follow these Step:
### 1. Clone Repository

```
git clone git@github.com:RixLux/Moody-Music.git
cd Moody-Music
```

### 2. Install Dependency

```
npm install
```

---

### 3. Create .env file
```
touch .env
```
Then follow these guide [env-setup](env-setup.md)

### 4. Run Server

**This one for development**

```
npm run dev
```

**OR**

```
npm run start
```

> Test this project yourself to see what it does.
